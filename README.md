# وكيل التداول الحلال — طريق المليون ريال

وكيل آلي يدير محفظة صغيرة من صناديق متداولة متوافقة مع الشريعة على **حساب Alpaca التجريبي** (أموال وهمية)، ويعمل يومياً عبر GitHub Actions.

## القواعد

| القاعدة | القيمة |
|---|---|
| الأدوات المسموحة فقط | SPUS 30%، HLAL 25%، UMMA 20%، SPSK 15%، SPRE 10% |
| أقصى وزن لأداة | 30% |
| وقف الخسارة | بيع المركز كاملاً عند خسارة 8% |
| فترة التبريد بعد وقف الخسارة | 30 يوماً بلا إعادة شراء |
| احتياطي نقدي | 2% |
| إعادة التوازن | فقط إذا ابتعد الوزن 5 نقاط عن هدفه |
| ممنوع | الرافعة، البيع على المكشوف، الخيارات، العقود، أي رمز خارج القائمة |

كل القواعد في `agent/config.py`.

## التشغيل

- **تلقائياً:** الإثنين إلى الجمعة، 6:45 مساءً بتوقيت الرياض.
- **يدوياً من الجوال:** تبويب **Actions** ← **Halal Trading Agent** ← **Run workflow**.

## المتابعة

- `latest_report.md` — تقرير آخر تشغيل (المحفظة والأوامر).
- `trades.csv` — سجل كل الصفقات.
- ملخص كل تشغيل يظهر أيضاً داخل صفحة التشغيل في تبويب Actions.

## المفاتيح

تُحفظ في **Settings ← Secrets and variables ← Actions** باسمي `ALPACA_API_KEY` و `ALPACA_SECRET_KEY`. لا تُكتب في الكود أبداً.

## تنبيهات

- حساب تجريبي فقط؛ الكود يرفض العمل على الحساب الحقيقي حتى يُعدّل عمداً.
- وقف الخسارة يُفحص مرة يومياً عند التشغيل، لا لحظياً.
- التوافق الشرعي معتمد على جهات إصدار الصناديق؛ توزيعات الأرباح قد تحتاج تطهيراً.
- لا يوجد ضمان ربح.
